۰. خلاصه اجرایی

سهام‌یار یک اپلیکیشن اندروید + وب است که براساس پورتفوی شخصی کاربر، پیشنهاد خرید و فروش سهام ارائه می‌دهد. تمایز اصلی این محصول نسبت به همه‌ی رقبای موجود در بازار ایران (bifilter، TsePlus، فست بورس، Arthika) ارائه‌ی پیشنهادهای contextual براساس ترکیب فعلی دارایی‌های کاربر است — نه فقط فیلترهای استاندارد.

محصول از چهار لایه‌ی تحلیلی تشکیل شده است: (۱) سیگنال پول هوشمند حقوقی، (۲) تحلیل تکنیکال خودکار، (۳) ارزش‌گذاری بنیادی، و (۴) تحلیل هم‌بستگی و تنوع پورتفو. این چهار لایه در یک الگوریتم Composite Score از ۰ تا ۱۰۰ ترکیب می‌شوند که به هر سهم یک توصیه‌ی قطعی (خرید قوی، خرید، نگه‌داری، کاهش وزن، فروش) اختصاص می‌دهد.

مشکل

  • bifilter و رقبا فیلترهای آماده می‌دهند اما پورتفوی کاربر را نادیده می‌گیرند
  • هیچ رقیبی هم‌بستگی و تنوع پورتفو را تحلیل نمی‌کند
  • «نرخ موفقیت ۷۱٪» bifilter بدون Backtest شفاف است
  • API رقبا کند (۱۴ ثانیه برای یک سیگنال!) و ناپایدار
  • هیچ ابزاری ریسک پورتفو (VaR) را نشان نمی‌دهد

راه‌حل

  • کاربر پورتفوی خود را وارد می‌کند (به‌صورت دستی یا OTP از کارگزاری)
  • سیستم روزانه Composite Score برای همه‌ی سهام بازار محاسبه می‌کند
  • ۵ پیشنهاد خرید + ۳ پیشنهاد فروش به‌صورت روزانه
  • Backtest شفاف: هر سیگنال با نتیجه‌ی ۳۰ روزه نمایش داده می‌شود
  • هشدار واگرایی پورتفو (مثلاً تمرکز ۳۰٪+ در یک گروه)

تمایز کلیدی (Unique Value Proposition)

تنها اپلیکیشن ایرانی که پیشنهاد خرید/فروش را براساس ترکیب پورتفوی کاربر می‌دهد، نه فقط فیلتر استاندارد. به‌علاوه، الگوریتم پیشنهاد به‌صورت شفاف با Backtest قابل بررسی ارائه می‌شود — چیزی که bifilter با ادعای مبهم «۷۱٪ موفقیت» فاقد آن است.

۱. معرفی محصول و Vision

۱.۱ نام و Vision

نام محصول: سهام‌یار (SahamYar)
تگ‌لاین: «مشاور هوشمند پورتفوی شما در بورس ایران»
Vision: تبدیل شدن به مرجع اصلی تصمیم‌گیری سرمایه‌گذاران خرد بورس ایران از طریق پیشنهادهای شفاف، مبتنی بر داده و قابل بررسی (Backtest) که در نهایت به افزایش شفافیت و کارایی بازار سرمایه کمک می‌کند.

۱.۲ Problem Statement

سرمایه‌گذاران خرد بورس ایران در مواجهه با پنج چالش اصلی هستند:

  1. عدم شخصی‌سازی: همه‌ی اپ‌های موجود (bifilter، فست بورس، TsePlus) فیلترهای یکسانی به همه‌ی کاربران ارائه می‌دهند، بدون در نظر گرفتن پورتفوی فعلی کاربر، ریسک‌پذیری و افق سرمایه‌گذاری.
  2. فقدان Backtest شفاف: bifilter ادعای «نرخ موفقیت ۷۱٪» دارد اما روش محاسبه و داده‌های تاریخی را منتشر نمی‌کند. کاربر نمی‌تواند اعتماد کند.
  3. کندی و ناپایداری: API bifilter روی برخی endpoint ها ۱۴ ثانیه زمان می‌برد و ۴ خطای ۵۰۰ در ۶۷ endpoint آزمایش‌شده مشاهده شد. این برای یک اپ real-time غیرقابل قبول است.
  4. هزینه‌ی بالا: پلن付费ی bifilter معادل ~۱.۵ میلیون تومان/ماه است که برای سرمایه‌گذاران متوسط (پورتفوی زیر ۵۰ میلیون) غیرمنطقی است.
  5. عدم تحلیل ریسک پورتفو: هیچ اپی VaR، هم‌بستگی دارایی‌ها، یا تمرکز صنعتی را به‌صورت یکپارچه ارائه نمی‌دهد.

-- ============================================================
-- سهام‌یار — Database Schema (PostgreSQL)
-- ============================================================

-- ۱. جدول نمادها (master data از TSETMC)
CREATE TABLE symbols (
    ins_code       VARCHAR(18) PRIMARY KEY,    -- 46348559193224090
    ticker         VARCHAR(20) NOT NULL,        -- فولاد
    fullname       VARCHAR(100),                -- فولاد مبارکه اصفهان
    sector_code    INT NOT NULL,                -- 27
    sector_name    VARCHAR(50),                 -- فلزات اساسی
    flow           INT,                         -- 1=bourse, 2=fara, 4=base
    status         VARCHAR(2),                  -- A=فعال, S=متوقف
    listed_at      DATE,
    updated_at     TIMESTAMP DEFAULT NOW()
);
CREATE INDEX idx_symbols_sector ON symbols(sector_code);
CREATE INDEX idx_symbols_ticker ON symbols(ticker);

-- ۲. کندل‌های روزانه (هسته‌ی داده‌ی بازار)
CREATE TABLE daily_candles (
    ins_code       VARCHAR(18) REFERENCES symbols(ins_code),
    date_jalali    INT NOT NULL,                -- 14050816
    open           DECIMAL(18,2),
    high           DECIMAL(18,2),
    low            DECIMAL(18,2),
    close          DECIMAL(18,2),               -- قیمت پایانی
    last_price     DECIMAL(18,2),               -- آخرین
    yesterday      DECIMAL(18,2),
    volume         BIGINT,
    trade_count    INT,
    value          BIGINT,                      -- ارزش (ریال)
    max_allowed    DECIMAL(18,2),               -- +۵٪
    min_allowed    DECIMAL(18,2),               -- -۵٪
    PRIMARY KEY (ins_code, date_jalali)
);
CREATE INDEX idx_candles_date ON daily_candles(date_jalali);

-- ۳. تفکیک خریدار حقیقی/حقوقی (طلایی!)
CREATE TABLE client_types (
    ins_code          VARCHAR(18) REFERENCES symbols(ins_code),
    date_jalali       INT NOT NULL,
    buy_real_count    INT,  sell_real_count   INT,
    buy_legal_count   INT,  sell_legal_count  INT,
    buy_real_volume   BIGINT, sell_real_volume   BIGINT,
    buy_legal_volume  BIGINT, sell_legal_volume  BIGINT,
    buy_real_value    BIGINT, sell_real_value    BIGINT,
    buy_legal_value   BIGINT, sell_legal_value   BIGINT,
    PRIMARY KEY (ins_code, date_jalali)
);

-- ۴. بنیادی (فصلی از کدال)
CREATE TABLE fundamentals (
    ins_code       VARCHAR(18) REFERENCES symbols(ins_code),
    fiscal_period  VARCHAR(10),                 -- 1405/Q1
    eps            DECIMAL(18,2),
    estimated_eps  DECIMAL(18,2),
    sector_pe      DECIMAL(8,2),
    nav            DECIMAL(18,2),               -- برای صندوق‌ها
    psv            DECIMAL(18,2),               -- ارزش بازار
    report_date    DATE,
    PRIMARY KEY (ins_code, fiscal_period)
);

-- ۵. اندیکاتورهای از‌پیش‌محاسبه‌شده ( crucial برای Performance)
CREATE TABLE indicator_snapshots (
    ins_code       VARCHAR(18) REFERENCES symbols(ins_code),
    date_jalali    INT NOT NULL,
    rsi_14         DECIMAL(5,2),
    mfi_14         DECIMAL(5,2),
    macd           DECIMAL(18,2),
    macd_signal    DECIMAL(18,2),
    ema_20         DECIMAL(18,2),
    ema_50         DECIMAL(18,2),
    ema_200        DECIMAL(18,2),
    volatility_30d DECIMAL(8,4),                -- std of daily returns
    PRIMARY KEY (ins_code, date_jalali)
);

-- ۶. Composite Score روزانه هر نماد
CREATE TABLE daily_scores (
    ins_code       VARCHAR(18) REFERENCES symbols(ins_code),
    date_jalali    INT NOT NULL,
    smart_money    DECIMAL(5,2),                -- -20..+20
    technical      DECIMAL(5,2),                -- 0..30
    fundamental    DECIMAL(5,2),                -- 0..20
    -- diversification به ازای هر کاربر محاسبه می‌شود
    total_base     DECIMAL(5,2),                -- 0..70 (بدون تنوع)
    action         VARCHAR(10),                 -- BUY/SELL/HOLD
    computed_at    TIMESTAMP DEFAULT NOW(),
    PRIMARY KEY (ins_code, date_jalali)
);
CREATE INDEX idx_scores_date_action ON daily_scores(date_jalali, action);

-- ۷. کاربران
CREATE TABLE users (
    id             SERIAL PRIMARY KEY,
    mobile         VARCHAR(11) UNIQUE NOT NULL, -- 09154165210
    email          VARCHAR(100),
    risk_profile   VARCHAR(10),                 -- conservative/balanced/aggressive
    created_at     TIMESTAMP DEFAULT NOW(),
    last_login     TIMESTAMP
);

-- ۸. پورتفوی کاربر (دارایی‌ها)
CREATE TABLE user_holdings (
    user_id        INT REFERENCES users(id),
    ins_code       VARCHAR(18) REFERENCES symbols(ins_code),
    quantity       BIGINT NOT NULL,
    buy_price      DECIMAL(18,2) NOT NULL,
    buy_date       DATE,
    notes          TEXT,
    PRIMARY KEY (user_id, ins_code)
);

-- ۹. اشتراک (Subscription)
CREATE TABLE subscriptions (
    id             SERIAL PRIMARY KEY,
    user_id        INT REFERENCES users(id),
    plan           VARCHAR(10),                 -- trial/pro_monthly/pro_yearly
    starts_at      TIMESTAMP NOT NULL,
    ends_at        TIMESTAMP NOT NULL,
    price_paid     BIGINT,                      -- تومان
    payment_ref    VARCHAR(50),                 -- مرجع زرین‌پال
    status         VARCHAR(10)                  -- active/expired/cancelled
);

-- ۱۰. پیشنهاد روزانه برای هر کاربر
CREATE TABLE recommendations (
    id             SERIAL PRIMARY KEY,
    user_id        INT REFERENCES users(id),
    ins_code       VARCHAR(18) REFERENCES symbols(ins_code),
    date_jalali    INT NOT NULL,
    score          DECIMAL(5,2),
    action         VARCHAR(15),                 -- strong_buy/buy/hold/reduce/sell
    reason_smart   TEXT,                        -- توضیح فارسی
    reason_tech    TEXT,
    reason_fund    TEXT,
    reason_div     TEXT,
    UNIQUE(user_id, ins_code, date_jalali)
);

-- ۱۱. Backtest نتایج
CREATE TABLE backtest_results (
    recommendation_id  INT REFERENCES recommendations(id),
    evaluated_at    DATE,                       -- ۳۰ روز پس از توصیه
    actual_return   DECIMAL(8,4),               -- درصد بازده واقعی
    benchmark_return DECIMAL(8,4),              -- بازده شاخص کل
    is_success      BOOLEAN,                    -- actual > threshold
    PRIMARY KEY (recommendation_id)
);

-- ۱۲. هشدارها و اعلان‌ها
CREATE TABLE notifications (
    id             SERIAL PRIMARY KEY,
    user_id        INT REFERENCES users(id),
    type           VARCHAR(20),                 -- distribution/rebalance/price
    ins_code       VARCHAR(18),
    title          VARCHAR(100),
    body           TEXT,
    created_at     TIMESTAMP DEFAULT NOW(),
    read_at        TIMESTAMP
);

۱۲.۲ استدلال قیمت‌گذاری

  • قیمت پایین: bifilter با ۱.۵M/ماه فقط به کاربران حرفه‌ای با پورتفوی ۱۰۰M+ دسترسی دارد. سهام‌یار با ۹۹K به کاربران با پورتفوی ۲۰M تا ۵۰M (که اکثریت بازار هستند) دسترسی پیدا می‌کند.
  • Trial ۷ روز: کاهش اصطکاک — کاربر قبل از پرداخت، محصول را ارزیابی می‌کند. این اعتماد می‌سازد که با «نرخ موفقیت ۷۱٪» bifilter فاقد آن است.
  • سالانه با تخفیف: افزایش cashflow و کاهش churn. کاربر سالانه LTV بیشتری دارد (۹۹۰K vs ۹۹K×۱۲=۱۱۸۸K، یعنی کم‌تر از سالانه).
  • تک‌پلن برای MVP: ساده‌سازی عملیات (یک نوع اشتراک، یک flow پرداخت، یک نوع refund). در فاز ۲ Quantum tier اضافه می‌شود.
